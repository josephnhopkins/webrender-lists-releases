# Webrender Lists — releases

Downloads for **Webrender Lists**, a small desktop program for your lists — a box on every row to
tick when it is done — kept in your Webrender Library, from Nextwaveweb Ltd. It needs a Webrender
account. What it is, the download links and what to expect on first run are on its page:

**https://nextwaveweb.co.uk/products/webrender-lists**

This repository holds no source code — only the released builds: one GitHub Release per
version, with the downloads as its assets. Every download carries a README (what you need,
connecting to your Library, the first-run warning, removal) and a `THIRD-PARTY-NOTICES.txt`
listing the open-source components it is built from — `README.txt` beside the program in the
Windows zip and in the folder the Windows installer installs to.

Windows is at 0.1.0. macOS and Linux follow.
